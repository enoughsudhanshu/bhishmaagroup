Sync Engine
Offline-First Philosophy &
Sync Architecture
1
Launch & Local DB Init
SQLite DB auto-created on first run. All operations write locally — instant, zero-latency.
2
Offline Queue
Every create/update/delete logged to sync queue with timestamps and device ID.
3
Internet Detected
Background thread continuously polls connectivity. No user action required.
4
Bidirectional Push/Pull
Queue flushed to cloud. Remote changes pulled. Vector-clock conflict resolution applied.
5
Reconciliation
Conflict logs surfaced to admin. Last-write-wins or field-level merge based on record type.

Deployment Architecture
1
PyInstaller Bundle
All Python runtime, Flask, libraries compiled into one self-contained binary.
2
NSIS Installer
Professional Windows Setup.exe with license agreement, install path, desktop shortcut.
3
Auto-Launch Service
Flask starts as background Windows service on boot. No user action needed.
4
SQLite Auto-Init
On first launch, DB schema created automatically. No database admin required.
5
Update Mechanism
Silent background updates with rollback support. Delta updates minimize bandwidth.
Security Architecture
🔐 Encrypted License Keys
Machine-bound licenses use RSA encryption. Keys tied to hardware fingerprint — non-transferable.
💾 Data Encryption at Rest
SQLite DB encrypted with SQLCipher. AES-256 encryption for all local stored sensitive data.
🔒 TLS in Transit
All sync traffic over HTTPS/TLS 1.3. Certificate pinning prevents MITM attacks.
👥 Role-Based Access Control
Granular permission matrix: Admin, Manager, Cashier, Accountant, Viewer roles.
