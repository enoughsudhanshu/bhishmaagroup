Platform Capabilities

Built for Real Aviation Ops

Not just a flight number lookup. A complete intelligence layer for tracking, monitoring, and analysing Indian aviation in real time.

📡

Live Position Tracking

Real-time lat/lon, altitude (ft), speed (km/h), and heading sourced from ADS-B transponders via OpenSky Network. Updates every 10–120 seconds based on flight phase.

ADS-B · OpenSky
🛬

Airport Dashboard

Live departure & arrival boards just like FIDS screens at airports. See terminal, gate, delay, and status for every flight at DEL, BOM, BLR, and 103 more airports.

106 Airports · FIDS
⏱️

Smart ETA Engine

Haversine great-circle distance calculation combined with real airspeed gives precise ETA in minutes. Updates live as the aircraft descends and decelerates.

Haversine · Live ETA
🔄

Adaptive Refresh Engine

No wasted API calls. The background refresh engine polls aggressively (10s) when a flight is landing and backs off to 10 minutes when it's cruising at altitude — saving thousands of API calls per day while keeping data fresh where it matters. Zero external calls when no flight is being tracked.

Zero-Waste Polling · APScheduler
🛡️

3-Layer Cache

Memory → Redis → SQLite cascade ensures instant responses. Cache hit rate stays above 95% for dashboard requests, meaning almost no live API calls on normal usage.

Memory · Redis · SQLite
📲

PWA — Install on Mobile

Progressive Web App with service worker. Install on Android or iOS home screen for a native app experience. Works offline with cached data.

PWA · Offline · Service Worker
🚨

VIP Flight Alerts

Automated alerts for final approach, landing, delay, holding pattern, and diversion. Built for VIP movement coordination and ground handling teams.

Real-time Alerts · WebSocket
🔁

Multi-API Fallback Chain

AirLabs → OpenSky → AviationStack. Quota-aware auto-switching between providers ensures the platform stays live even when one API hits rate limits.

Fallback · Quota-Aware
📈

Flight History & Analytics

Every position update stored as a time-series. Export flight paths as KML (Google Earth) or GeoJSON. Daily traffic reports and delay analytics built in.

KML · GeoJSON · Analytics

Under The Hood

How It Works

A zero-waste data pipeline — from raw ADS-B signals to your dashboard in under a second.

01
Background Fetch

APScheduler silently polls OpenSky (positions every 90s) and AirLabs (schedules every 5 min) in background threads — completely independent of user requests.

02
3-Layer Cache Write

Fresh data is written simultaneously to RAM, Redis, and SQLite — so it's instantly available in microseconds next time.

03
User Requests Dashboard

Frontend calls /api/dashboard/DEL — server reads from cache, computes progress %, interpolates position, attaches weather. Zero external API call.

04
WebSocket Push

When new position data arrives for a tracked flight, Socket.IO immediately pushes the update to all connected clients — live without polling.

Technology

Open Source Stack. Production Grade.

Built entirely on proven open-source tools — deployable on any VPS for under ₹500/month.

Python + Flask
Lightweight REST API server with CORS, rate-limiting, and error handling baked in.
Flask-SocketIO
WebSocket layer for real-time bidirectional push — no polling from frontend.
SQLAlchemy + SQLite
ORM-backed persistent storage with WAL mode for safe concurrent read/write.
APScheduler
Background job scheduler for adaptive polling — the refresh engine that never sleeps.
OpenSky Network
Free ADS-B position data for India — 500+ aircraft simultaneously tracked.
AirLabs API
Schedules, delays, gates, terminals — primary data source for all airports.
Redis (Optional)
Distributed cache layer — enables multi-worker horizontal scaling.
PWA + Service Worker
Installable, offline-capable dashboard for mobile ground teams.
